# 格式卷轴 ScrollFormat — 二期功能设计（推演与细化）

> 在《前期架构2.md》基础上，针对当前版本（M1+M2+部分M4）的下一步实现做细化规划。
> 当前范围：图片 / 文档(占位) / 音频 / 视频 / 任务列表 / 设置。环境检测、日志保留命令与代码，UI 暂隐藏。

## 1. 目标

1. 每个类型 TAB 有该领域的专业参数调节。
2. 参数进入任务 `options.extra`，转换器真实生效。
3. 任务队列、取消、重试、持久化、崩溃恢复已具备，本期增强：预估、日志细化。
4. 文档 TAB 保持参数面板占位（提示将接入 pandoc/libreoffice）。

## 2. 参数设计（写入 `ConvertOptions.extra`）

### 2.1 图片 image
| 参数 | 类型 | 取值 | 说明 |
|---|---|---|---|
| quality | u8 | 10-100 | JPEG/WebP 质量 |
| max_side | u32? | null/1920/1280/2560 | 长边缩放 |
| strip_metadata | bool | true/false | 去除 EXIF |

### 2.2 音频 audio
| 参数 | 类型 | 取值 | 说明 |
|---|---|---|---|
| bitrate | string | 128k/192k/256k/320k | 码率 |
| sample_rate | string | 44100/48000 | 采样率 |
| channels | u32 | 1/2 | 声道 |

### 2.3 视频 video
| 参数 | 类型 | 取值 | 说明 |
|---|---|---|---|
| crf | u8 | 18-35 | 质量（越小越清晰） |
| scale | string | original/1920:-2/1280:-2/854:-2 | 分辨率 |
| fps | string | original/24/30/60 | 帧率 |
| preset | string | ultrafast/veryfast/fast/medium | 编码速度 |

### 2.4 文档 document（占位）
page_range / dpi / embed_fonts / ocr（UI 展示，转换返回「尚未实现」）。

## 3. UI 结构

- 横向 TAB：图片 / 文档 / 音频 / 视频 / 任务列表，右侧设置按钮（弹窗）。
- 主区：拖拽区 → 文件列表 → 「高级参数」可折叠面板（按 kind 切换内容）→ 输出格式 / 预设 / 输出目录 / 开始转换。
- 任务列表：子 TAB（全部/排队/进行中/已完成/失败/已取消）+ 进度、取消、重试、删除。

## 4. 实施顺序

1. 扩展 `ConvertOptions.extra` 读取（image.rs 缩放/去元数据、av.rs 码率/采样率/声道/CRF/scale/fps/preset）。
2. 前端 KindTab 增加按 kind 的高级参数面板，透传到 create_task。
3. cargo check + npm build 验证。
4. 后续：M3 文档真实实现、预览面板、预设市场、自动更新。
