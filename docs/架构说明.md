## 3. 核心抽象

### 3.1 Converter trait（crates/core/converter.rs）

```rust
pub trait Converter: Send + Sync {
    fn id(&self) -> &'static str;
    fn name(&self) -> &'static str;
    fn supported_inputs(&self) -> &[&str];
    fn supported_outputs(&self) -> &[&str];
    async fn probe(&self, input: &Path) -> Result<FormatInfo>;
    async fn preview(&self, input: &Path) -> Result<PreviewData>;
    async fn convert(&self, ctx: ConvertContext) -> Result<ConvertOutput>;
}
```

`ConvertContext` 携带：`input`、`output`、`options`（含 `extra` 参数包）、`cancel: CancellationToken`、`progress: mpsc::Sender<f32>`、`log: mpsc::Sender<String>`。

**新增转换器只需两步**：实现 trait → 在 `registry_ext::build_default_registry()` 中按 `FormatKind` 注册。

### 3.2 参数通道（ConvertOptions.extra）

前端把整个高级参数区序列化为 `extra: serde_json::Value`，后端按需读取，**新增参数不需要改后端结构体**：

| 类型 | extra 字段 |
|---|---|
| 图片 | `scale_mode`、`max_side`、`percent`、`filter`、`depth`、`flatten`、`bg` |
| 音频 | `bitrate`(含 `lossless`)、`sample_rate`、`channels`、`codec`、`loudnorm`、`keep_meta`、`custom_args` |
| 视频 | `crf`、`scale`、`fps`、`enc_preset`、`v_codec`、`deinterlace`、`faststart`、`a_codec`、`a_bitrate`、`a_sample_rate`、`a_channels`、`custom_args` |

### 3.3 命名引擎（crates/core/naming.rs）

`render_output_name(rule, source, index) -> Result<String>`
支持 `{name}` `{originalName}` `{index}` `{index:03}` `{timestamp}` `{timestamp_full}` `{ext}`；
非法占位符/未闭合/非法字符返回 `FMT-USER-003`。
前端 `buildTemplate()` 由「前缀 + 序号开关 + 时间开关 + {name} + 后缀」拼装模板，套用预设时 `parseTemplate()` 反解回界面状态。

### 3.4 错误码（crates/core/error.rs）

| 码 | 含义 |
|---|---|
| `FMT-ENV-001` / `FMT-ENV-002` | 环境检测失败 / 外部工具缺失 |
| `FMT-CONV-001` / `FMT-CONV-002` | 转换失败 / 不支持的格式 |
| `FMT-IO-001` / `FMT-IO-002` | 文件读写失败 / 输出目录不可写 |
| `FMT-PROC-001` / `FMT-PROC-002` | 外部进程失败 / 超时 |
| `FMT-USER-001` ~ `FMT-USER-004` | 取消 / 参数非法 / 命名规则无效 / 预设损坏 |

## 4. 任务模型与状态机

```
                 ┌──────────┐
   create_task → │  Queued  │
                 └────┬─────┘
      pause ↓          │ scheduler 取出（非 Queued 直接跳过）
   ┌──────────┐        ▼
   │  Paused  │ ←── ┌─────────┐   cancel   ┌───────────┐
   └────┬─────┘    │ Running │ ─────────▶ │ Cancelled │
        │ resume   └────┬────┘             └───────────┘
        └───────▶ Queued │ error
                         ▼
                 ┌───────────┐   ok    ┌───────────┐
                 │  Failed   │ ──────▶ │ Completed │
                 └───────────┘         └───────────┘
```

- 一个 `Task` 对应**一个文件**（创建时即拆分），`items` 仍保留以便将来支持多文件任务
- 暂停：仅置状态 + 取消当前进程，**不重新入队**；运行中的 `run_task` 收尾时识别 `Paused` 保持不变
- 继续：`Paused → Queued`，重置进度/错误/输出后重新入队并唤醒调度器
- 进度事件经 `ServiceEvent::TaskProgress` 广播，由前端直接驱动进度条（不轮询整表）

## 5. 调度与并发

- 队列：有界优先队列（`VecDeque<Uuid>` + `Notify` 唤醒）
- 并发：`max_parallel`（`AtomicUsize`，可在设置中运行时调整，来自 `settings.json`）
- 取消：`tokio_util::sync::CancellationToken`，`ProcessRunner` 在 select 分支中 kill 子进程
- 超时：`settings.command_timeout_secs > 0` 时对整个 item 转换加 `tokio::time::timeout`
- 进度节流：ffmpeg `-progress pipe:1` 输出经 channel 聚合，UI 端 spring 动画平滑

## 6. 外部进程调用（crates/infra/process.rs）

```
RunSpec { program, args: Vec<String>, timeout, cancel, on_stdout, on_stderr }
```

- 仅 `Command::new` + 参数数组，**无 shell 拼接**
- Windows 下使用 `CREATE_NO_WINDOW` 避免弹窗
- stdout/stderr 分离回调；stderr 同时写入 SQLite 日志表
- 退出码非 0 → `FMT-PROC-001`；超时 → `FMT-PROC-002`；取消 → `FMT-USER-001`
- 用户自定义参数在 `converters::av::extra_args()` 中按空白切分为独立参数后追加

工具解析顺序（`paths::find_tool`）：
`settings 手动指定 → sidecar（exe 同级 / sidecars/）→ PATH → 常见安装目录`

## 7. 持久化

`crates/infra/db.rs`（SQLite，`{app_data}/scrollformat.db`）

| 表 | 说明 |
|---|---|
| `tasks` | 任务主表：状态、优先级、参数 JSON、目录模式、命名规则、错误、耗时 |
| `settings` | 预留键值表（当前设置以 `settings.json` 文件形式保存） |
| `logs` | 任务日志 |

启动迁移：读取 `PRAGMA table_info(tasks)`，缺失列（`output_dir_mode` / `naming_json`）自动 `ALTER TABLE` 补齐。

崩溃恢复：`recover()` 把 `running/probing` 标记为中断失败；`reload_from_db` 将 `Queued` 重新入队。

数据目录解析：`SCROLLFORMAT_DATA_DIR` → 项目根（含 `Cargo.toml` 与 `crates/`）下 `.scrollformat/` → cwd 下 `.scrollformat/`。

### 8.1 设计令牌（ui/src/index.css）

- 关键色：`--accent` / `--accent-soft`，21 个预设 + 自定义取色（`body[data-accent]`）
- 文字层级：`--fg` / `--fg-2` / `--fg-3`（深浅色各自取值，保证对比度）
- 磨砂：`--glass-blur` / `--glass-sat` / `--glass-alpha` / `--glass-border-alpha`，设置界面用 `.glass-fixed` 锁定不被自身滑竿影响
- 选中态：`.tab-active`（关键色邻近渐变 + 细描边 + 主题本色文字）

### 8.2 事件订阅与回收

- 任务事件（`task://*`）经 `listen` 订阅，组件卸载时 `unlisten` 全部执行
- 拖拽监听为**全局单例**（`lib/useDragDrop.ts`），避免重复注册
- 下拉/右键/框选等 fixed 弹层统一 `createPortal(document.body)`，规避 `backdrop-filter` 形成包含块导致的定位偏移
- 预览结果使用 `Map` + 上限 LRU，组件卸载时清空

## 10. 扩展指南

**新增转换器（如 PDF）**
1. `crates/converters/src/pdf.rs` 实现 `Converter`
2. 在 `registry_ext.rs` 用 `reg.register(FormatKind::Document, Arc::new(PdfConverter))` 替换占位
3. `core/src/format.rs` 补充 `detect_kind` 映射（如新扩展名）
4. `ui/src/lib/kinds.ts` 打开对应页签并把 `ready: true`
5. 如引入新外部工具：在 `infra/src/paths.rs` 增加手动指定项与 sidecar 名称

**新增参数**
1. 前端 `KindTab` 增加控件 → 写入 `extraParams()`
2. `handlePreset` 中回填（保证预设可还原）
3. 后端在 `convert()` 内读取 `ctx.options.extra` 并映射为 ffmpeg 参数或编码选项

**新增设置项**
1. `crates/infra/src/settings.rs` 增加字段（`#[serde(default)]` 保证旧配置兼容）
2. `src-tauri/src/commands.rs` 的 `SettingsPatch` 增加字段
3. `ui/src/lib/api.ts` 的 `Settings` 接口 + 设置面板控件
